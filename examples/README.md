# Projetos executáveis

## SaaS Tenant Dashboard

**[Abrir projeto →](./saas-tenant-dashboard/README.md)**

Exemplo Next.js + React + TypeScript feito para ser clonado, aberto no VS Code, executado localmente e evoluído via Git.

```bash
git clone https://github.com/Videirafo/SaaS-Engineering-Playbook.git
cd SaaS-Engineering-Playbook/examples/saas-tenant-dashboard
code .
npm install
npm run dev
```

O CI executa typecheck e production build para validar que o starter continua executável.
