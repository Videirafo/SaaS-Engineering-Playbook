# Suporte

Use Issues para bugs reproduzíveis, dúvidas de execução, documentação incompleta e propostas técnicas relacionadas ao projeto.

Inclua quando possível: sistema operacional, versão do runtime, passos mínimos para reproduzir, comportamento esperado/observado e logs sanitizados.

Não publique tokens, senhas, `.env` reais, chaves privadas, dados de clientes ou endpoints internos sensíveis.

Para vulnerabilidades, siga [SECURITY.md](./SECURITY.md).

Este projeto é um playbook e laboratório técnico público; não oferece SLA ou suporte comercial para ambientes de terceiros.
