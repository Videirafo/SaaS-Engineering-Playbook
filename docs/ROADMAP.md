## v1.0 — Playbook estável

Critérios:

- documentação consistente;
- exemplos reproduzíveis;
- licença definida;
- CI verde;
- feedback externo incorporado;
- issues adequadas para novos contribuidores;
- pelo menos um release versionado.

## Ideias para contribuição

Contribuições pequenas e verificáveis são preferidas:

- corrigir conceitos/links;
- melhorar exemplos;
- adicionar casos de falha;
- revisar acessibilidade da documentação;
- criar testes conceituais;
- adicionar diagramas como código;
- documentar trade-offs entre arquiteturas.

O roadmap não é uma promessa de prazo. Ele representa direção técnica e pode mudar conforme feedback e uso real.
