# Claude Code — regras locais, piloto experimental

Este arquivo **não** instala Superpowers, Karpathy Skills, I Have ADHD nem Claude Octopus. Fornece apenas compatibilidade metodológica para agentes que leem `CLAUDE.md`.

- Antes de programar: verificar issue, contexto, premissas e requisitos.
- Evitar abstrações novas, código especulativo e alterações fora do escopo.
- Buscar evidência RED → GREEN e testar regressões de falha.
- Escrever a resposta com ação, estado, no máximo cinco passos e próxima ação.
- Revisões concorrentes fictícias não representam IAs independentes; jamais converter `PASS_PILOT` em autorização de deploy.
- Respeitar sempre TRUST GATE, autorização humana e regras do repositório.
